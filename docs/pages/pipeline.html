The pipeline

video_rag() runs every stage on one video. workflow runs it, then the aggregators.

video_rag()

from vidra.video_rag import video_rag video_rag(source, into, video_id=None, on_conflict="new", name=None, recorded_at=None, policy="uniform", use_video=True, use_audio=True, sampler="uniform", vlm=None, embedder=None, resume=True, database=None, on_step=None, models=None) -> Run
from vidra import LocalEmbedder, Models, OpenAI, Supabase
from vidra.video_rag import video_rag

models = Models(vlm=OpenAI("gpt-5.4-mini"), embedder=LocalEmbedder())
run = video_rag("shop.mp4", "data/out", policy="scene", sampler="clip,yolo",
                models=models, database=Supabase())

The policy, samplers, questions, model keys and database are all checked before the first stage; every problem is raised together as one Refused.

AttributeIs

skipped{stage: why} for stages that did not run.

run.video_id                  # "shop"
run.folder                    # Path("data/out/shop")
run.artifacts()               # {"descriptions": ".../descriptions.json", ...}
run.skipped                   # {"audio": "the file carries no audio stream"}
for step in run.steps:
    print(step.component, step.stats)

What runs, in what order

The policy decides the order:

PolicyOrder
uniformmedia, audio, boundaries, video, cut, describe, embed
scenemedia, audio, boundaries.evidence (decodes the picture), boundaries, video, cut, describe, embed
vad, speakermedia, audio, boundaries.evidence (reads the transcript), boundaries, video, cut, describe, embed

Stages that don't apply are skipped with a reason, e.g. audio on a silent file. A policy needing a stream the file lacks is refused.

Each stage runs with its defaults: Whisper small and pyannote, scene threshold 27, chunks of 5 to 20 s, one frame per second. To change them, run the stages directly.

Progress: on_step

on_step(component, produced) is called before each stage (with None) and after it (with its Produced). With a third parameter it also gets a Progress for each unit of work in video, describe and embed:

def on_step(component, produced, progress=None):
    if progress is not None:
        print(f"  {component} {progress.completed}/{progress.total} "
              f"({progress.skipped} reused) {progress.current}")
    elif produced is None:
        print("start", component)
    else:
        print("done ", component, produced.stats)

video_rag("shop.mp4", "data/out", sampler="clip", on_step=on_step)

Progress has component, total, completed, skipped, current (e.g. 3:clip) and result. Describe reports in completion order. Raising in the callback stops the run.

Options, process, validate

video_rag() is shorthand for these:

from pathlib import Path
from vidra.video_rag import Options, process, validate

options = Options(source=Path("shop.mp4"), into=Path("data/out"), policy="scene",
                  sampler="clip", vlm=OpenAI(), embedder=LocalEmbedder())
problems = validate(options)          # [] when the request is valid; nothing runs
if not problems:
    run = process(options, on_step=None)

Options has video_rag()'s fields except on_step and models. validate(options) returns every problem as a list; process(options, on_step) runs it.

layout()

layout(folder) gives every artifact's path in a video's folder:

from vidra.video_rag import layout

at = layout("data/out/shop")
at["timeline"]          # Path("data/out/shop/timeline.json")
at["store"]             # Path("data/out/shop/store")

workflow: both tiers

workflow.process runs video_rag, then every aggregator up to a cost tier. Answers go to <folder>/aggregates/ and are reused while current.

from pathlib import Path
from vidra import LocalEmbedder, Models, OpenAI, Supabase, workflow

run = workflow.process(workflow.Options(
    source=Path("shop.mp4"), sampler="clip,yolo", policy="scene", tier="llm",
    models=Models(vlm=OpenAI(), llm=OpenAI(), embedder=LocalEmbedder()),
    database=Supabase()))

answers = run.steps[-1]                   # the aggregate step's receipt
answers.artifacts                         # {"summary": ".../aggregates/summary.json", ...}
answers.stats["skipped"]                  # {"speakers": "...", ...}
workflow.Options(source, into=None, video_id=None, name=None, recorded_at=None, policy="uniform", use_video=True, use_audio=True, sampler="uniform", vlm=None, embedder=None, llm=None, tier="free", database=None, models=None)

An aggregator with nothing to read (speakers on a silent video) is skipped with the reason. To choose inputs yourself, run the aggregates directly.

  • workflow.validate(options) lists every problem either tier would raise, including a missing LLM key.
  • workflow.process(options, on_step) reports "aggregate" as a final step.
  • workflow.extraction(options) returns the video_rag.Options part.
  • workflow.Run is a Run with the aggregate step last in steps.

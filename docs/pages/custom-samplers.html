Custom samplers

Your own rule for which frames are kept, used anywhere a built-in sampler is: in video_rag, in video_rag_live and in the video stage.

In short

Subclass Sampler, give it a name, and fill in propose: keep this frame or not. Then put an object of it in a spec.

from vidra import Sampler
from vidra.video_rag import video_rag

class Bright(Sampler):
    """Keep a frame when it is brighter than `level` (0-255)."""
    name = "bright"

    def __init__(self, level=120, min_interval_s=0.0, max_per_chunk=None,
                 sampler_id=None, prompts=None):
        super().__init__(min_interval_s, max_per_chunk, sampler_id, prompts)
        self.level = level

    def propose(self, frame, chunk_local_index):
        return frame.image.mean() > self.level

    def config(self):
        return {**self._base_config(), "level": self.level}

video_rag("x.mp4", "data/out", sampler=[Bright(level=140, prompts=["overview"]), "clip"])

The run decodes once and offers every decimated frame to both samplers. The frames bright keeps are described with the overview question and stored as bright:overview, beside clip's answers.

The Sampler class

class Sampler(min_interval_s=0.0, max_per_chunk=None, sampler_id=None, prompts=None)
MemberIs
nameA class attribute: the strategy's name, written in specs and stored with every answer (motion:overview). Lowercase letters, digits, _, -.
propose(frame, chunk_local_index)Required. Keep this frame? frame.image is the picture (BGR, borrowed: copy what you keep), frame.media_ts its time in seconds, frame.index its number in the video. chunk_local_index counts decimated frames in this chunk from 0.
on_reset(chunk_id)Called when a chunk opens, before its first frame: reset the strategy's state here.
config()What the manifest records about the run: {**self._base_config(), ...your settings}, plain JSON.
last_score()Optional: a number recorded beside each kept frame, e.g. how much the picture changed.
__init__(...)Your settings first, then min_interval_s, max_per_chunk, sampler_id and prompts, passed to super().__init__.
Base settingIs
min_interval_sSmallest gap, in media seconds, between two kept frames.
max_per_chunkAt most this many kept frames per chunk; None for no limit.
sampler_idThe run's key in the manifest; None is name.
promptsThe questions asked about the kept frames; none means the question named after the sampler.

What the base class does

  • Rate limits come first. A frame inside min_interval_s of the last kept one, or past max_per_chunk, is refused before propose sees it. When propose returns True, the frame is kept.
  • Every chunk keeps its first frame. propose is still called on it, and its answer is ignored: the place to take a reference.
  • One frame at a time. A sampler cannot look ahead or revisit a frame. The same class runs on a file and on a live stream.

State between frames

Keep what the next frame needs on self, and clear it in on_reset: a reference picture, a count, the last score. Each run uses its own shallow copy of your object, so a model loaded in __init__ is shared between runs while state assigned in on_reset belongs to one run. Assign new values there rather than changing a list or dict made in __init__, which every copy shares.

def on_reset(self, chunk_id):
    self.reference = None              # each chunk starts afresh

def propose(self, frame, chunk_local_index):
    small = frame.image[::8, ::8].mean(axis=2)
    if self.reference is None:         # the chunk's first frame: kept anyway
        self.reference = small
        return True
    moved = abs(small - self.reference).mean() / 255
    if moved >= self.threshold:
        self.reference = small         # compare with the last kept frame
        return True
    return False

Using it

As an object

Put the object in the sampler list of video_rag, video_rag_live or video.video, beside names and other objects. It carries its own settings and questions. One sampler is one run: two objects with the same name, or a name and an object of the same sampler, are refused, so put every question on one object (prompts=["overview", "safety"]).

By name

from vidra.video_rag import samplers

samplers.register(Bright)              # or @samplers.register above the class

video_rag("x.mp4", "data/out", sampler="bright:overview,clip")
samplers.build("bright", level=90, prompts=["overview"])   # an object, configured

samplers.register(cls) lets spec strings name the class, in this process. A built-in's name (samplers.BUILTIN), a name a spec string cannot carry, or an abstract class is refused; registering a name again replaces the class. samplers.class_of(name) is the class a name builds and samplers.available() lists every name.

A registered sampler named in a spec string gets the settings passed beside it, when its constructor takes them: video.video(..., sampler="motion", threshold=0.2) reaches the motion sampler's threshold. A setting no named sampler takes is refused.

Questions

A sampler named alone asks the question named after it, and yours has none. Give it prompts=[...], pair it in a spec (bright:overview), or add a question with its name using describe.add_question. Otherwise the run is refused before anything decodes.

Reading its output elsewhere

Search and the aggregates read the files, so a run's output stays readable in a process that never registered the class, and answers to a custom question stay readable where the question is not defined (another data root, another machine): a record vouches for the samplers and questions its answers came from, with the fields they carry.

Complete example: motion

Keeps a frame when enough of the picture moved since the last kept frame: no model, a downscaled difference. For fixed cameras only; on a moving camera nearly every frame moves. It runs the sampler as an object and by name, on a file and live.

docs/pages/examples/custom_sampler.py
"""A sampler of your own: keep a frame when enough of the picture moved.

Cheap -- no model, a downscaled difference -- and for fixed cameras only. On
shop CCTV, threshold 0.10 kept 10-18% of decimated frames (CLIP at its default
keeps 13-18% there) and ignored sensor noise, which 0.05 and below did not. A
moving camera or an edited film changes nearly every pixel every second: it
kept 30-76% even at 0.45. Use `clip` for those.

    python custom_sampler.py path/to/video.mp4
"""

import sys

import numpy as np

import vidra
from vidra import Folder, LocalEmbedder, Models, OpenAI, Sampler
from vidra.video_rag import samplers, video, video_rag, video_rag_live

vidra.configure(env_file=".env")


class Motion(Sampler):
    """Keep a frame when the share of pixels that changed since the last kept
    frame reaches `threshold`."""

    name = "motion"                     # written in specs and stored with answers

    def __init__(self, threshold=0.10, scale=8, min_interval_s=0.0,
                 max_per_chunk=None, sampler_id=None, prompts=None):
        super().__init__(min_interval_s, max_per_chunk, sampler_id, prompts)
        self.threshold, self.scale = threshold, scale
        self._last_score = None

    def on_reset(self, chunk_id):
        self.reference = None           # every chunk starts afresh

    def propose(self, frame, chunk_local_index):
        # frame.image is BGR and borrowed: copy anything kept past this call.
        small = frame.image[::self.scale, ::self.scale].mean(axis=2)
        if self.reference is None:
            self.reference, self._last_score = small.copy(), None
            return True                 # the first frame of a chunk is kept anyway
        moved = float((np.abs(small - self.reference) > 25).mean())
        self._last_score = moved
        if moved >= self.threshold:
            self.reference = small.copy()
            return True
        return False

    def last_score(self):
        return self._last_score         # recorded beside each kept frame

    def config(self):
        # What the manifest records about the run: plain JSON only.
        return {**self._base_config(), "threshold": self.threshold, "scale": self.scale}


source = sys.argv[1]
models = Models(vlm=OpenAI("gpt-5.4-mini"), embedder=LocalEmbedder())

# An object carries its own settings and questions; a built-in is configured
# the same way through samplers.build.
run = video_rag(source, "data/out", use_audio=False, models=models,
                sampler=[Motion(threshold=0.10, prompts=["overview"]),
                         samplers.build("uniform", every_n=10, prompts=["overview"])],
                database=Folder("data/out"))
manifest = video.load(run.folder / "manifest.json")
for sid in ("motion", "uniform"):
    print(sid, "kept per chunk:",
          [c["samplers"].get(sid, {}).get("frame_count", 0) for c in manifest.chunks])

# Registered, it can be named in a spec string too, with any question.
samplers.register(Motion)
print("samplers:", samplers.available())
live = video_rag_live(source, "data/out", video_id="motion-live",
                      sampler="motion:overview", models=models)
print(live.observations, "answers from motion:overview, lag", live.lag_s)

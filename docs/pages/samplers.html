Samplers

Which frames of each chunk are kept and sent to the vision model.

How sampling works

  1. The video is decoded once, however many samplers run.
  2. Frames are offered at per_second (default 1), by media time, so variable frame rates don't matter.
  3. Each sampler keeps the offered frames its strategy picks. The first frame of each chunk is always kept.
  4. min_interval_s and max_per_chunk apply before the strategy, so a frame they rule out costs no model time.
  5. Samplers reset at each chunk boundary: "changed" means changed within the chunk.
  6. Kept frames go to store/ (one file even if two samplers keep it) and are listed in manifest.json.

Pass samplers to video_rag(sampler=...), or to video.video along with their settings.

uniform

Keeps every every_n-th offered frame, counted from each chunk's start. No model. At per_second=1, every_n=5 is one frame every 5 s; for a fixed interval in seconds use min_interval_s.

For even coverage, or to ask something on a schedule: uniform:text reads the screen periodically with no OCR.

SettingDefault
every_n1: every offered frame

clip

Embeds each frame with CLIP (openai/clip-vit-base-patch32) and keeps it when its similarity to the last kept frame drops below threshold, so slow pans still trigger once they drift far enough. The general-purpose choice.

SettingDefaultEffect
threshold0.96Lower keeps fewer frames.

yolo

Finds people with YOLO (yolo11n.pt), embeds each person's crop with CLIP, and keeps the frame when someone in view no longer matches anyone in the last kept frame. People leaving don't trigger it. Crowds trigger often; pair with min_interval_s.

Its question returns one entry per person: appearance, clothing, role, action and fixed-vocabulary attributes (gender, age group, hair, top and bottom colour and type, accessories). entities:people links these across chunks.

SettingDefaultEffect
threshold0.83Lower keeps fewer frames.

objects

Detects the objects in vocabulary with YOLO-World (yolov8s-worldv2.pt) and keeps the frame when detections no longer match the last kept frame's by class and position. Its question is told the vocabulary and returns one entry per object (object, appearance, context).

SettingDefaultEffect
vocabularyshopping bag, plastic bag, shopping cart, shopping basket, cardboard box, bottle, grocery item, cash registerWhat to detect. Set it for your footage; a mismatched list finds half as much and mislabels.
confidence0.30Minimum detection confidence.
threshold0.30Lower keeps fewer frames.

text

Locates text with EasyOCR's detector (nothing is read here) and keeps the frame when the text layout changes. Its question transcribes each piece of text with its context. For slides, screens and signs.

The most expensive sampler: the detector is ~98% of its time. If text changes on a schedule, uniform:text gets the same result without it.

SettingDefaultEffect
languages["en"]EasyOCR language codes, e.g. ["en", "de"].
threshold0.92Lower keeps fewer frames.

A setting no chosen sampler reads is refused. video.SAMPLER_SETTINGS is this table as data: {setting: (samplers)}. A value applies to every sampler that reads it: threshold=0.9 with clip,yolo sets both.

from vidra.video_rag import video

video.video(D / "media.json", D / "timeline.json", D / "manifest.json", store=D / "store",
            sampler="clip,objects", threshold=0.9,
            vocabulary=["forklift", "pallet", "hard hat"], confidence=0.4,
            min_interval_s=2.0, max_per_chunk=5)

Choosing a threshold

Thresholds don't transfer between videos. clip at 0.96 on three similar shop videos:

VideoFrames keptTypical similarity, 1 s apart
test.mp413.4%0.9868
test2.mp418.0%0.9895
test1.mp459.2%0.9605

Busier footage keeps more. To control cost, use min_interval_s or max_per_chunk: they keep the most-changed frames and even out chunks. A lower threshold leaves busy chunks with many frames and quiet ones with one.

Sampler specs

The sampler argument names samplers and, optionally, their questions:

SpecMeansAnswer ids
clipclip's frames, clip's own questionclip
uniform:textevery Nth frame, asked to read the screenuniform:text
yolo:overviewframes where people changed, as short proseyolo:overview
clip:[text,scene]one pass, two questionsclip:text, clip:scene
clip:text+scenethe same, without bracketsclip:text, clip:scene
clip,yolotwo samplers, one decodeclip, yolo
clip,clip:checkoutone clip pass, its own question and checkoutclip, clip:checkout
  • Specs naming the same sampler merge into one pass: clip:text,clip:scene is clip:[text,scene]. An extra question on the same frames costs one more call per chunk.
  • Questions must exist (built in or added); unknown ones are refused before decoding.
  • Question names can't contain , : [ ] +.
  • A list also works: sampler=["clip", "uniform:text"].

Models run on CUDA, then mps, then CPU. Weights download on first use to weights/ (or VIDRA_WEIGHTS); CLIP uses Hugging Face's cache.

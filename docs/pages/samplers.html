Samplers

Which frames of each chunk are kept and sent to the vision model.

How sampling works

  1. The video is decoded once, however many samplers run.
  2. Frames are offered at per_second (default 1), by media time, so variable frame rates don't matter.
  3. Each sampler keeps the offered frames its strategy picks. The first frame of each chunk is always kept.
  4. min_interval_s and max_per_chunk apply before the strategy, so a frame they rule out costs no model time.
  5. Samplers reset at each chunk boundary: "changed" means changed within the chunk.
  6. Kept frames go to store/ (one file even if two samplers keep it) and are listed in manifest.json.

Pass samplers to video_rag(sampler=...), or to video.video along with their settings.

uniform

Keeps every every_n-th offered frame, counted from each chunk's start. No model. At per_second=1, every_n=5 is one frame every 5 s; for a fixed interval in seconds use min_interval_s.

For even coverage, or to ask something on a schedule: uniform:text reads the screen periodically with no OCR.

SettingDefault
every_n1: every offered frame

clip

Embeds each frame with CLIP (openai/clip-vit-base-patch32) and keeps it when its similarity to the last kept frame drops below threshold, so slow pans still trigger once they drift far enough. The general-purpose choice.

SettingDefaultEffect
threshold0.96Lower keeps fewer frames.

yolo

Finds people with YOLO (yolo11n.pt), embeds each person's crop with CLIP, and keeps the frame when someone in view no longer matches anyone in the last kept frame. People leaving don't trigger it. Crowds trigger often; pair with min_interval_s.

Its question returns one entry per person: appearance, clothing, role, action and fixed-vocabulary attributes (gender, age group, hair, top and bottom colour and type, accessories). entities:people links these across chunks.

SettingDefaultEffect
threshold0.83Lower keeps fewer frames.

objects

Detects the objects in vocabulary with YOLO-World (yolov8s-worldv2.pt) and keeps the frame when detections no longer match the last kept frame's by class and position. Its question is told the vocabulary and returns one entry per object (object, appearance, context).

SettingDefaultEffect
vocabularyshopping bag, plastic bag, shopping cart, shopping basket, cardboard box, bottle, grocery item, cash registerWhat to detect. Set it for your footage; a mismatched list finds half as much and mislabels.
confidence0.30Minimum detection confidence.
threshold0.30Lower keeps fewer frames.

text

Locates text with EasyOCR's detector (nothing is read here) and keeps the frame when the text layout changes. Its question transcribes each piece of text with its context. For slides, screens and signs.

The most expensive sampler: the detector is ~98% of its time. If text changes on a schedule, uniform:text gets the same result without it.

SettingDefaultEffect
languages["en"]EasyOCR language codes, e.g. ["en", "de"].
threshold0.92Lower keeps fewer frames.

A setting no sampler named in the spec takes is refused. Each goes to the samplers whose constructor takes it, so a sampler of your own with a threshold parameter gets one too. video.SAMPLER_SETTINGS is this table as data for the built-ins: {setting: (samplers)}. A value applies to every sampler that reads it: threshold=0.9 with clip,yolo sets both.

from vidra.video_rag import video

video.video(D / "media.json", D / "timeline.json", D / "manifest.json", store=D / "store",
            sampler="clip,objects", threshold=0.9,
            vocabulary=["forklift", "pallet", "hard hat"], confidence=0.4,
            min_interval_s=2.0, max_per_chunk=5)

Setting a sampler up per call

The settings above reach a sampler only when you call the video stage yourself. To set them for video_rag or video_rag_live, build the sampler and put the object in the spec: it carries its own settings and questions, and a spec may mix objects and names.

from vidra.video_rag import samplers, video_rag

video_rag("x.mp4", "data/out",
          sampler=[samplers.build("clip", threshold=0.93, prompts=["safety"]),
                   samplers.build("objects", vocabulary=["forklift", "pallet"],
                                  confidence=0.4, prompts=["objects"]),
                   "yolo"])

samplers.build(name, **settings) takes the settings that sampler's class takes, plus min_interval_s, max_per_chunk and prompts (its questions; none means its own). samplers.available() lists every name. Each run uses its own copy of the object, so one object can serve several runs or cameras without their per-chunk state mixing. One sampler is one run: naming clip and passing a clip object in one spec is refused, so put every question on the object.

Choosing a threshold

Thresholds don't transfer between videos. clip at 0.96 on three similar shop videos:

VideoFrames keptTypical similarity, 1 s apart
test.mp413.4%0.9868
test2.mp418.0%0.9895
test1.mp459.2%0.9605

Busier footage keeps more. To control cost, use min_interval_s or max_per_chunk: they keep the most-changed frames and even out chunks. A lower threshold leaves busy chunks with many frames and quiet ones with one.

Sampler specs

The sampler argument names samplers and, optionally, their questions:

SpecMeansAnswer ids
clipclip's frames, clip's own questionclip
uniform:textevery Nth frame, asked to read the screenuniform:text
yolo:overviewframes where people changed, as short proseyolo:overview
clip:[text,scene]one pass, two questionsclip:text, clip:scene
clip:text+scenethe same, without bracketsclip:text, clip:scene
clip,yolotwo samplers, one decodeclip, yolo
clip,clip:checkoutone clip pass, its own question and checkoutclip, clip:checkout
  • Specs naming the same sampler merge into one pass: clip:text,clip:scene is clip:[text,scene]. An extra question on the same frames costs one more call per chunk.
  • Questions must exist (built in or added); unknown ones are refused before decoding.
  • Question names can't contain , : [ ] +.
  • A list also works: sampler=["clip", "uniform:text"].

Writing your own

Subclass Sampler and fill in propose. Pass an object of it in a spec, or register the class to name it in spec strings.

MemberIs
nameA class attribute: the strategy's name, written in specs and stored with every answer (motion:overview). Lowercase letters, digits, _, -.
propose(frame, chunk_local_index)Required. Keep this frame? frame.image is the picture (BGR, borrowed: copy what you keep), frame.media_ts its time, frame.index its number in the video. chunk_local_index counts decimated frames in this chunk from 0.
on_reset(chunk_id)Called when a chunk opens: reset the strategy's state here. Assign new values rather than mutating shared ones, since a run uses a shallow copy of your object.
config()What the manifest records about the run: {**self._base_config(), ...your settings}, plain JSON.
last_score()Optional: a number recorded beside each kept frame.
__init__(..., min_interval_s=0.0, max_per_chunk=None, sampler_id=None, prompts=None)Your settings, then these four passed to super().__init__. Your settings are then reachable from samplers.build, and from the video stage's keyword of the same name.

The base class does the rest, the same for every sampler: min_interval_s and max_per_chunk are applied before propose runs, and every chunk keeps its first frame. A sampler sees one frame at a time and cannot look ahead, which is what lets the same class run on a file and on a live stream.

Questions. A sampler named alone asks a question named after it, which yours does not have: give it prompts=[...], pair it in a spec (motion:overview), or add a question with its name (describe.add_question). Otherwise the run is refused before anything decodes.

Registering with samplers.register(cls) (also a class decorator) lets a spec string name it, in this process. A built-in's name, or one a spec string cannot carry, is refused; registering a name again replaces the class. Output it wrote stays readable where it is not registered, and answers to a custom question where that question is not defined (another data root, another machine): the aggregates read the files, and a record vouches for the samplers and questions its answers came from, with the fields they carry. samplers.class_of(name) is the class a name builds; samplers.BUILTIN the names that ship.

docs/pages/examples/custom_sampler.py
"""A sampler of your own: keep a frame when enough of the picture moved.

Cheap -- no model, a downscaled difference -- and for fixed cameras only. On
shop CCTV, threshold 0.10 kept 10-18% of decimated frames (CLIP at its default
keeps 13-18% there) and ignored sensor noise, which 0.05 and below did not. A
moving camera or an edited film changes nearly every pixel every second: it
kept 30-76% even at 0.45. Use `clip` for those.

    python custom_sampler.py path/to/video.mp4
"""

import sys

import numpy as np

import vidra
from vidra import Folder, LocalEmbedder, Models, OpenAI, Sampler
from vidra.video_rag import samplers, video, video_rag, video_rag_live

vidra.configure(env_file=".env")


class Motion(Sampler):
    """Keep a frame when the share of pixels that changed since the last kept
    frame reaches `threshold`."""

    name = "motion"                     # written in specs and stored with answers

    def __init__(self, threshold=0.10, scale=8, min_interval_s=0.0,
                 max_per_chunk=None, sampler_id=None, prompts=None):
        super().__init__(min_interval_s, max_per_chunk, sampler_id, prompts)
        self.threshold, self.scale = threshold, scale
        self._last_score = None

    def on_reset(self, chunk_id):
        self.reference = None           # every chunk starts afresh

    def propose(self, frame, chunk_local_index):
        # frame.image is BGR and borrowed: copy anything kept past this call.
        small = frame.image[::self.scale, ::self.scale].mean(axis=2)
        if self.reference is None:
            self.reference, self._last_score = small.copy(), None
            return True                 # the first frame of a chunk is kept anyway
        moved = float((np.abs(small - self.reference) > 25).mean())
        self._last_score = moved
        if moved >= self.threshold:
            self.reference = small.copy()
            return True
        return False

    def last_score(self):
        return self._last_score         # recorded beside each kept frame

    def config(self):
        # What the manifest records about the run: plain JSON only.
        return {**self._base_config(), "threshold": self.threshold, "scale": self.scale}


source = sys.argv[1]
models = Models(vlm=OpenAI("gpt-5.4-mini"), embedder=LocalEmbedder())

# An object carries its own settings and questions; a built-in is configured
# the same way through samplers.build.
run = video_rag(source, "data/out", use_audio=False, models=models,
                sampler=[Motion(threshold=0.10, prompts=["overview"]),
                         samplers.build("uniform", every_n=10, prompts=["overview"])],
                database=Folder("data/out"))
manifest = video.load(run.folder / "manifest.json")
for sid in ("motion", "uniform"):
    print(sid, "kept per chunk:",
          [c["samplers"].get(sid, {}).get("frame_count", 0) for c in manifest.chunks])

# Registered, it can be named in a spec string too, with any question.
samplers.register(Motion)
print("samplers:", samplers.available())
live = video_rag_live(source, "data/out", video_id="motion-live",
                      sampler="motion:overview", models=models)
print(live.observations, "answers from motion:overview, lag", live.lag_s)
